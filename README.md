# 별빛 전선 · 갤러그

## GitHub Pages로 공개하기
1. GitHub에서 새 저장소를 만들고 공개(Public)로 설정합니다.
2. 이 폴더의 `index.html`을 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 배포 원본으로 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
4. Pages에 표시되는 주소로 게임을 공유합니다. 게시까지 몇 분 걸릴 수 있습니다.

이 게임은 브라우저에서 실행되는 단일 HTML 파일입니다. 별도 서버나 빌드 과정이 필요하지 않습니다.
